# Recipe Recommendation System with Gemini Integration

This project develops a sophisticated recipe recommendation system leveraging Natural Language Processing (NLP) with TensorFlow Keras, enhanced by the Gemini API for creative recipe variations and meal planning. The system processes recipe data, generates embeddings, predicts user ratings, and provides a Flask-based API for seamless integration.

## Project Goals

- **Data Cleaning & Preparation**: Process raw recipe and nutritional data.
- **NLP-based Embeddings**: Create rich vector representations of recipes using text features (title, ingredients, steps).
- **Rating Prediction**: Develop a model to predict user ratings for recipes.
- **Triplet Loss Training**: Enhance embedding quality for better similarity-based recommendations.
- **Generative AI Integration**: Utilize the Gemini API to generate creative recipe variations and detailed meal plans based on recommendations.
- **REST API**: Implement a Flask API to serve the rating prediction model.

## Features

- **Recipe Data Processing**: Cleans and consolidates various recipe attributes.
- **Text Vectorization & Embeddings**: Transforms text data into numerical embeddings suitable for machine learning.
- **Hyperparameter Tuning**: Optimizes model performance using KerasTuner for the rating prediction model.
- **Triplet Loss Optimization**: Improves the semantic understanding of recipe embeddings.
- **Recipe Recommendation Functionality**: Recommends recipes based on user ingredient preferences and dynamic category detection.
- **Dynamic Recipe Variations**: Generates unique and creative recipe variations using the Gemini API.
- **Personalized Meal Plans**: Creates high-protein or healthy meal plans inspired by existing recipes with Gemini.
- **Production-Ready API**: A Flask API (`app.py`) to deploy and use the `best_rating_prediction_model` for real-time rating predictions.

## Models

1.  **NLP_Recommendation_Model**: This is the core embedding model that takes recipe features (title, ingredients, steps, numerical attributes like calories and age suitability, and food category) and outputs a 32-dimensional embedding vector. This model is trained with triplet loss to ensure semantically similar recipes have closer embeddings.
2.  **Rating_Prediction_Model**: A separate model built on top of the `NLP_Recommendation_Model`'s embeddings, designed to predict a user's rating for a given recipe. This model's architecture and hyperparameters are optimized using KerasTuner.

To set up this project locally or in a Colab environment:

1.  **Clone the repository**:
    ```bash
    git clone <your-repository-url>
    cd <your-repository-name>
    ```

2.  **Install Dependencies**:
    The project relies on `pandas`, `tensorflow`, `scikit-learn`, `keras-tuner`, `flask`, and `google-generativeai`. You can install them using pip:
    ```bash
    !pip install pandas tensorflow scikit-learn keras-tuner Flask google-generativeai
    ```

3.  **Data Files**:
    Ensure the following CSV files are present in your working directory (e.g., `/content/` in Colab):

    - `nlp_recommendation_model.keras`: The saved NLP embedding model.
    - `best_rating_prediction_model.keras`: The saved best rating prediction model.
    - `app.py`: The Flask API script for serving the rating prediction model.

## Usage

### Running the Recommendation System (in Notebook)

Execute the cells in the provided Colab notebook sequentially to:
1.  Load and preprocess data.
2.  Train the NLP embedding model.
3.  Train and tune the rating prediction model.
4.  Generate recipe embeddings and use the recommendation functions.
5.  Interact with the Gemini API for recipe variations and meal plans.

### Running the Flask API

To run the Flask API locally (or in a Colab environment):

1.  **Start the Flask application**:
    ```bash
    !python -m flask run --port 5000
    ```
    (In Colab, this will run in the background. You might need to use `subprocess.Popen` for better control as shown in the notebook).

2.  **Test the API** (e.g., using `curl` or Python `requests`):
    ```python
    import requests
    import json

    payload = {
        "Title_processed": "ayam woku manado",
        "Ingredients_processed": "1 ekor ayam kampung potong 12",
        "Steps_processed": "cuci bersih ayam dan tiriskan",
        "jumlah_kalori_normalized": 0.5,
        "usia_normalized": 0.3,
        "Food_Category": "ayam"
    }
    response = requests.post('http://127.0.0.1:5000/predict_rating', json=payload)
    print(response.json())
    ```
